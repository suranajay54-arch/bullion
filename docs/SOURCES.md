# Source registry

Generated by `node pipeline/docs.js` from config/sources.json and data/registry/. Do not edit by hand.

Each source says how it is obtained, whether this public site may display it and why, how often it changes, when the page marks it STALE, and what happens when it fails.

## Sources

### ECB euro foreign exchange reference rates (EUR/USD, EUR/INR) (`ECB-EXR`)

| Field | Value |
|---|---|
| Publisher | European Central Bank |
| Role | Market USD/INR reference (via cross rate) |
| Access | AUTOMATED |
| Status | CONNECTED |
| Where | https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist-90d.xml |
| Terms | Free use if reproduced accurately and the ECB is cited as the source; any modification must be stated explicitly. Rates are published for information purposes only. (C-ECB-DISCLAIMER) |
| Public display | Allowed. ECB reuse policy permits reproduction with attribution; the USD/INR cross is labelled as derived. |
| Cadence | Each TARGET working day, around 16:00 CET/CEST. No rates on weekends or TARGET closing days (1 Jan, Good Friday, Easter Monday, 1 May, 25 and 26 Dec). |
| Observation time | Daily concertation at about 14:15 Frankfurt time (Europe/Berlin). |
| Goes stale when | STALE if no newer observation by 16:00 Europe/Berlin on the next TARGET business day, plus 20 h grace. |
| Delay and handling | Reference fixing, not a tradable quote. Published about 1 h 45 min after the concertation. |
| Failure modes | Network or TLS failure: keep the last valid observation from the previous snapshot, marked STALE when overdue; Format change: parse fails, adapter records an error and keeps the last valid observation; TARGET holiday: no new row is expected and nothing is flagged |
| Retry | 3 attempts with 2 s, 6 s, 18 s backoff; 20 s timeout per attempt |

- **VERIFIED**: Primary document read on an official host (government, exchange, central bank or the publisher itself).

- **SECONDARY**: Reported by a named secondary source (news agency, newspaper, broker, consultancy). Primary document not located.
- **CITATION PENDING**: Carried over from the earlier evidence brief; no document located yet. Not presented as fact.
